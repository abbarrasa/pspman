# Archive compatibility fixtures

These are test data only. Never execute archived binaries or use proprietary game data here. The probe hashes decoded payload into discard streams; it does not extract games onto any mounted device.

## Provenance and licence

All 33 binary fixture files are unmodified copies from [SharpCompress 0.50.9 test archives](https://github.com/adamhathcock/sharpcompress/tree/0.50.9/tests/TestArchives/Archives), downloaded during Spec 005 task T01. The inspected upstream Git tree SHA was `760eef37ab0b31162065ac16e8923ea6f09d896c`. Their exact bytes are recorded in [SHA256SUMS](./SHA256SUMS) and verified by an automated test. The upstream [MIT licence](./LICENSE.SharpCompress.txt) is retained. No archive-generation executable is required to run the suite.

The package and upstream test corpus are not evidence that every archive is compatible. In particular, upstream itself expects rejection for its encrypted multipart RAR sample in [RarArchiveTests](https://github.com/adamhathcock/sharpcompress/blob/0.50.9/tests/SharpCompress.Test/Rar/RarArchiveTests.cs). PSPMan records that limitation rather than treating it as successful extraction. Independent reference-tool validation of that sample has not been performed in T01.

## Expected decoded files

Hashes were computed independently from the upstream [Original](https://github.com/adamhathcock/sharpcompress/tree/0.50.9/tests/TestArchives/Original) blobs. These originals are not copied separately into this repository.

| --- | ---: | --- |
| `exe/test.exe` | 45056 | `8557928804f57ecc340b3bb38b095a3607474ec8deb0076f316fcfe02b562106` |
| `jpg/test.jpg` | 40372 | `b251c7501fb0f55dd4a92feabe0a6f5733bc40a02679498155fae9b30138fc53` |
| `тест.txt` | 15498 | `4d581d93d369f6e1c9b295ff38d82dabd577f927dfaf0c35818c015c85e322d9` |

The original text blob has LF endings (15044 bytes, SHA-256 `1a3de4e51eb2f58672e42443b0e8ea618ba464931166539498ff2ab77eec3838`), whereas these archives contain CRLF. The expected 15498-byte hash was computed by replacing LF with CRLF in the independently downloaded original. Total decoded size is 100926 bytes. No production text conversion is intended.

The corpus includes legacy CP866 ZIP names without a Unicode encoding declaration. The probe explicitly supplies CP866 as the known corpus encoding; this is a fixture configuration, not an approved automatic production encoding policy. UTF-8-declared archive entries retain their own encoding.

## Families and passwords

- `Zip.deflate.zip`: plain ZIP and nested/cyrillic names.
- `Zip.zip64.zip`: ZIP64 metadata and extraction.
- `Zip.deflate.WinzipAES.zip`: AES ZIP, fixture password `test`.
- `Zip.deflate.pkware.zip`: traditional-encryption ZIP, fixture password `12345678`; its payload is different from the three-file original corpus.
- `WinZip26.nocomp.multi.zip` and `.z01`: true split ZIP, seekable archive API; `.zip` is the control file.
- `Rar4.rar`, `Rar5.rar`, `Rar5.solid.rar`: regular RAR4, RAR5 and solid RAR5.
- `Rar.encrypted_filesOnly.rar`, `Rar.encrypted_filesAndHeader.rar`, corresponding `Rar5.*`: encrypted data and encrypted headers, password `test`.
- `Rar5.multi.part01.rar` through `part06.rar`: modern multipart RAR5.
- `Rar2.multi.rar` plus `.r00` through `.r05`: legacy multipart RAR.
- `Rar.EncryptedParts.part01.rar` through `part06.rar`: encrypted multipart limitation sample, password `test`.
- `Zip.lzma.WinzipAES.zip`: encrypted LZMA ZIP limitation sample, password `test`.

Plain empty ZIP and two-entry stored ZIP fixtures are generated by .NET in per-test temporary directories. Corruption tests flip a payload byte in the first or second entry while preserving its recorded CRC; they do not mutate filenames or shared fixtures. Missing-part and cancellation tests use private fixture copies. Dispose only those test-owned temporary directories.

## Running and interpreting the gate

Run from the repository root:

```sh
dotnet test tests/PSPMan.Infraestructure.Tests/PSPMan.Infraestructure.Tests.csproj --filter FullyQualifiedName~ArchiveCompatibility
```

The tests characterize the proposed backend. Tests asserting a known rejection are successful observations, not successful support of that archive variant. See [T01 compatibility report](../../../../specs/005-copy-games/archive-compatibility.md) for the gate verdict and required decisions. Do not mark T01 complete merely because all characterization tests pass.
